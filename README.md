# Believe It! — 25 Years of Naruto Uzumaki

An immersive, interactive tribute to Naruto Uzumaki and the 25th anniversary
of *NARUTO*.

**Live experience:** [believe-it-25-years-naruto-uzumaki.vercel.app](https://believe-it-25-years-naruto-uzumaki.vercel.app/)

**Site credit:** [SAYED SADIQ](https://www.linkedin.com/in/sayed-sadiq45/) ·
[GitHub](https://github.com/SayedSadiq45)

> “まっすぐ自分の言葉は曲げねえ” — Never go back on your word.

## The experience

Travel through a cinematic story told with scroll-driven animation, original
visual effects, and interactive reveals:

- **Sage Mode:** Move through the story to awaken Naruto's Sage Mode, frame by
  frame.
- **The swing:** Scroll through a rain-soaked memory in a hand-picked sequence
  of animated frames.
- **The bonds:** Brush away the darkness to reveal the people who stood beside
  Naruto.
- **Interactive details:** Discover the hero artwork with a cursor-lit reveal,
  subtle chakra-inspired effects, and an animated anniversary seal.
- **Responsive by design:** Explore on desktop or mobile, with reduced-motion
  preferences respected.

## Built with

- React 18
- Vite 5
- HTML canvas and CSS animations
- Lenis smooth scrolling

## Run locally

You'll need Node.js 18 or later and npm.

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal. To make a production
build and serve it locally:

```bash
npm run build
npm run preview
```

## Project structure

```text
src/
  components/   Story sections, canvas scenes, and loading experience
  lib/          Artwork loading and shared canvas helpers
  reactbits/    Reusable visual effects
  App.jsx       Page composition and loading orchestration
  styles.css    Responsive layouts, typography, and animation
public/
  media/        Web-optimized artwork and animation frames
```
